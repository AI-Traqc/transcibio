Funktionen

Was Transcibio für Sie erledigt

Von der Aufnahme bis zum fertigen Protokoll, ohne dass ein Wort Ihren Rechner verlässt.

Transkribieren

Audiodatei hochladen (.mp3, .wav) oder direkt aufnehmen. Sie bekommen den Text mit Zeitangaben und Sprechern.

Bearbeiten

Wörter korrigieren und Sprecher benennen: Aus „SPEAKER_00“ wird „Frau Keller“, überall im Transkript.

Fragen mit Quellen

Fragen in eigenen Worten stellen. Jede Antwort zeigt, aus welcher Stelle der Aufnahme sie stammt.

Schnellbuttons

Zusammenfassen, Kernpunkte herausziehen, Sprecher erkennen oder ins Englische übersetzen, mit einem Klick.

Sprachmodus

Laut fragen und die Antwort hören, ganz ohne Tastatur. Auf Deutsch oder Englisch.

Entwürfe

Transcibio schlägt E-Mails und Aufgabenlisten vor. Sie prüfen sie und speichern sie als Dateien.

Installieren

Transcibio auf Ihren Rechner holen

Keine Vorkenntnisse nötig. Sie installieren zwei kostenlose Programme (Docker und Ollama), laden Transcibio herunter und starten es per Doppelklick. Den Rest erledigt das Startprogramm.

Hilfe

Wenn etwas nicht klappt

Die häufigsten Stolpersteine und Fragen. Wählen Sie Ihr System oder suchen Sie nach einem Stichwort.

Häufige Probleme

„Der Computer wurde durch Windows geschützt“

Klicken Sie auf Weitere Informationen und dann auf Trotzdem ausführen. Die Meldung erscheint, weil die Startdatei aus dem Internet stammt.

Die Startdatei lässt sich nicht öffnen

Öffnen Sie Systemeinstellungen → Datenschutz & Sicherheit und klicken Sie unten bei „Transcibio.command“ auf Dennoch öffnen. Bei älteren macOS-Versionen: Rechtsklick auf die Datei → Öffnen und bestätigen.

Der erste Start dauert sehr lange

Das ist normal. Beim ersten Mal lädt das Startprogramm mehrere Gigabyte und baut die App, das dauert 20 bis 40 Minuten. Lassen Sie das Fenster offen. Ab dem zweiten Start geht es in wenigen Sekunden.

„Docker laeuft nicht“

Öffnen Sie Docker Desktop und warten Sie, bis es läuft (Windows: „Engine running“, Mac: Wal-Symbol steht ruhig). Unter Linux: sudo systemctl start docker.

Docker meldet „permission denied“

Fügen Sie Ihr Konto der Gruppe docker hinzu: sudo usermod -aG docker $USER. Danach ab- und wieder anmelden.

„Ollama ist nicht erreichbar“

Öffnen Sie die Ollama-App. Unter Linux: systemctl start ollama oder ollama serve.

Im Transkript stehen keine Sprecher

Dafür braucht Transcibio den Hugging-Face-Token (siehe Installationsschritt „Sprechererkennung freischalten“). Sie können ihn nachträglich eintragen: Öffnen Sie die Datei .env im Projektordner mit einem Texteditor, schreiben Sie HF_TOKEN=hf_… hinein und starten Sie Transcibio neu.

Auf dem Mac ist die Datei versteckt: im Finder ⌘+Umschalt+. drücken.

Die Transkription dauert lange

Stellen Sie unter Settings → Transcription → Whisper model auf Fast. Am meisten hilft eine NVIDIA-Grafikkarte.

Der Rechner wird langsam, der Speicher reicht nicht

Wählen Sie ein kleineres Chat-Modell oder senken Sie in der Datei .env den Wert TRANSCIBIO_OLLAMA_NUM_CTX (mindestens 16384).

„Invalid host header“

Öffnen Sie die App über http://localhost:8080.

Der Upload wird abgelehnt

Möglich sind .mp3- und .wav-Dateien.

Die Transkription scheitert mit „Nemotron“

Der Nemotron-Server läuft nicht. Stellen Sie in den Settings zurück auf Whisper, oder tragen Sie COMPOSE_PROFILES=nemotron in .env ein und starten Sie die App neu. Zeigen die Settings „Server is starting“, lädt der Server noch (etwa 5 Minuten).

Etwas anderes

Die Protokolle zeigen, was passiert: scripts/transcibio.sh logs (Windows, in PowerShell: scripts\transcibio.ps1 logs).

Kommen Sie nicht weiter, beschreiben Sie das Problem in einem GitHub-Issue. Fügen Sie dort keine Tokens oder vertraulichen Inhalte ein.

Nichts gefunden. Versuchen Sie ein anderes Stichwort.

Fragen und Antworten

Was kostet Transcibio?

Nichts. Transcibio ist Open Source unter der MIT-Lizenz. Auch Ollama und die Modelle sind kostenlos, Docker Desktop für Privatpersonen und kleine Unternehmen. Für die Modelle gelten jeweils eigene Nutzungsbedingungen.

Brauche ich Internet?

Nur beim ersten Start, um Programme und Modelle herunterzuladen (mehrere Gigabyte), und für Updates. Danach arbeitet Transcibio offline.

Wo liegen meine Daten?

Im Ordner data/ des Projektordners auf Ihrem Rechner: Aufnahmen, Transkripte, Chats und Entwürfe. Es gibt kein Konto und keine Cloud. Löschen können Sie alles in der App unter Settings → Danger zone.

Welche Sprachen versteht Transcibio?

Die Transkription ist auf Deutsch und Englisch ausgelegt; Whisper erkennt die Sprache selbst. Fragen stellen Sie auf Deutsch oder Englisch. Vorlesen und Sprachmodus gibt es auf Deutsch (Piper) und Englisch (Kokoro). Die Oberfläche der App ist auf Englisch.

Wie lang dürfen Aufnahmen sein?

Mit Whisper gibt es keine Längenbegrenzung. Die optionale zweite Engine Nemotron schafft bis zu 60 Minuten pro Aufnahme.

Wie schnell ist die Transkription?

Das hängt vom Rechner ab. Mit einer NVIDIA-Grafikkarte geht es schnell, nur mit dem Prozessor dauert es deutlich länger. In den Settings wählen Sie zwischen Fast (am schnellsten), Balanced und Quality (am genauesten).

Läuft es auch auf dem Mac?

Ja. Die Transkription läuft dort auf dem Prozessor, weil Docker die Apple-Grafik nicht nutzen kann. Das Chat-Modell nutzt sie über Ollama.

Kann mein Team gemeinsam darauf zugreifen?

Transcibio ist für einen Rechner gedacht und hat keine Anmeldung. Deshalb antwortet es nur auf diesem Rechner. Wer den Zugriff von anderen Geräten erlauben möchte, trägt deren Namen in TRANSCIBIO_ALLOWED_HOSTS ein; das Mikrofon braucht dann https://.

Wie entferne ich Transcibio wieder?

Beenden Sie die App und löschen Sie den Projektordner. In Docker Desktop entfernen Sie unter Images die Transcibio-Images, das Chat-Modell mit ollama rm gemma4:e4b. Docker und Ollama deinstallieren Sie wie andere Programme.

Ist das Demo auf dieser Seite die echte App?

Nein. Das Demo spielt die Oberfläche mit einem erfundenen Beispielmeeting und vorbereiteten Antworten nach. Die echte App arbeitet mit Ihren Aufnahmen und einem echten Sprachmodell.

Bereit für Ihr erstes Transkript?

Die Installation dauert etwa eine Stunde, das meiste davon lädt von selbst. Danach gehört Ihnen ein Assistent, der nichts weitererzählt.
